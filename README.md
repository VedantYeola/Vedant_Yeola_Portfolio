# Vedant Yeola - Portfolio

A modern, interactive portfolio website built with React, TypeScript, and Three.js.

## 🚀 Tech Stack

- **React 19** - UI Framework
- **TypeScript** - Type Safety
- **Vite** - Build Tool
- **Three.js** - 3D Graphics
- **Tailwind CSS** - Styling

## ✨ Features

- 🎨 5 Accent Color Themes (Indigo, Emerald, Rose, Cyan, Orange)
- 🌙 Dark/Light Mode Toggle
- 🌐 Interactive 3D Animated Background
- 📱 Fully Responsive Design
- 🎯 Smooth Scroll Navigation
- 📄 Resume Download
- 🔗 Social Links (GitHub, LinkedIn)

## 📁 Project Structure

```
├── components/
│   ├── Navbar.tsx      # Navigation with theme & accent switcher
│   ├── ProjectCard.tsx # Project display cards
│   └── Scene3D.tsx     # Three.js 3D background
├── public/
│   └── Vedant_Yeola_Resume.pdf  # Resume file
├── App.tsx             # Main application
├── constants.ts        # Portfolio data (projects, skills, education)
├── types.ts            # TypeScript interfaces
└── index.tsx           # Entry point
```

## 🛠️ Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 📝 Customization

Edit `constants.ts` to update:
- Personal information
- Projects
- Skills
- Education
- Achievements
